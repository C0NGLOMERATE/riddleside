# Риддлсайд · промо-сайт

Промо-сайт визуальной новеллы «Риддлсайд» (приложение Lagerta). Сайт статический и работает на GitHub Pages без сервера.

## Где что лежит

- `index.html`: страница.
- `content.js`: **все тексты сайта на русском и английском**: досье, карта, звонки, форум, штрафы, достижения, ссылки. Чтобы поправить текст, меняй строку в этом файле.
- `app.js`: логика (кабинет, телефон, компьютер, радио, достижения).
- `style.css`: оформление.
- `assets/img`: картинки, `assets/snd`: звуки и музыка.

## Частые правки

- **Дата релиза на календаре:** в `content.js` найди `releaseDay: null` и поставь число октября, например `releaseDay: 31`.
- **Ссылки на магазины, канал, плейлист, Инстаграм Тайлера:** блок `links` в начале `content.js`.
- **Номера телефонов персонажей:** блок `numbers` там же.

Прогресс посетителя (достижения) хранится только в его браузере.
